# Melody Editor

Creates a libmelodyeditor.so - a plugin for [LMMS](https://github.com/LMMS/lmms/) under Qt5/Qt6. 

You will have to [compile this source code](references/LMMS.md) along with LMMS code base.

## Parsers Supported

Parser              | Mode   | Readable Link                                   | Depends on
--------------------|--------|-------------------------------------------------|-------------
ABC Parser          | Basic  | [Quick Manual](references/abc/README.md)        | [ABC-parser](https://github.com/MeesCode/ABC-parser/)
Alda Parser         | Basic  | [Quick Manual](references/alda/README.md)       |
Bhatkhande Parser   | Basic  | [Quick Manual](references/bhatkhande/README.md) | Expressions and song structure macros
English Parser      | Basic  | [Quick Manual](references/english/README.md)    | English Dialect
SARGAM Parser       | Basic  | [Quick Manual](references/sargam/README.md)     | Hindustani and Carnatic Dialect
